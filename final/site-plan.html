2. Site Purpose

Ruta Ecuador is a travel guide website designed to help visitors discover interesting destinations throughout Ecuador. The website will provide information about destinations from the Coast, Sierra, Amazon, and Galápagos regions.

Visitors will be able to explore destinations, search and filter locations according to their interests, view detailed destination information, save favorite destinations, and submit their travel preferences through a trip-planning form.

The main goal of the website is to make discovering places in Ecuador easier and more engaging for travelers.

4. Site Content

The website will contain information about destinations throughout Ecuador. Destinations will be organized by geographic region and type of experience.

Regions

  • Sierra
  • Coast
  • Amazon
  • Galápagos

Destination Types

  • Nature
  • Adventure
  • Beach
  • Culture
  • Wildlife
  • Hiking
  • City
  • Relaxation

Destination Information

Each destination will contain at least four properties retrieved from a JSON data source.

  • Name
  • Province
  • Region
  • Type
  • Description
  • Best time to visit
  • Estimated cost
  • Image

9. Typography

Primary Font

A clean sans-serif font will be used throughout the website to provide a modern appearance and good readability.

Typography Hierarchy

  • Large headings for page titles and the hero section.
  • Medium headings for sections and destination names.
  • Regular body text for descriptions and information.
  • Bold text for important information and calls to action.

10. Navigation

The primary navigation will appear consistently on every page.

Ruta Ecuador | Home | Destinations | Plan Your Trip

On small screens, the navigation links will be hidden behind a hamburger menu. Clicking the hamburger button will reveal the navigation links.

The current page will use wayfinding to help visitors understand where they are within the website.
