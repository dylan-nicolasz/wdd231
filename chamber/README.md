# WDD 231 Chamber Directory

Open the `chamber` folder with VS Code and use Live Server (or another local web server).

Important:
- `directory.html` is the first project page.
- `data/members.json` supplies the member data.
- `scripts/directory.js` uses fetch() and async/await.
- `styles/normalize.css` must load before `small.css` and `larger.css`.
- The website is designed for 320px and wider.
- Replace the example GitHub URL in the Open Graph `og:url` with your actual URL.
- Replace the fictional business information with your own site-plan information if required.
